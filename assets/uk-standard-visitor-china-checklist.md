# UK Standard Visitor from mainland China / 英国标准访客签证中国大陆案件清单

This is a case-building template, not a universal document list. Delete non-applicable rows and add items produced by the current official checklist.

## Route / 路线确认

- [ ] Ordinary PRC passport / 中国大陆普通护照
- [ ] Applying from mainland China / 在中国大陆申请
- [ ] Main purpose recorded / 已记录主要目的
- [ ] Stay no more than six months / 停留不超过六个月
- [ ] No excluded or special-purpose branch overlooked / 未遗漏排除项或特殊目的分支
- [ ] Permitted activities verified from current rules / 已按当前规则核验允许活动

## Identity and application / 身份与申请

- [ ] Passport valid for whole planned stay / 护照覆盖整个计划停留期
- [ ] Travel dates and accommodation plan / 旅行日期与住宿计划
- [ ] Estimated trip cost and payer / 预计费用与付款人
- [ ] Address and residence history required by live form / 当前表格要求的地址与居住信息
- [ ] Family, partner, UK contacts, and parents data where requested / 表格要求的家庭、伴侣、英国联系人及父母信息
- [ ] Travel and immigration history / 旅行及移民历史
- [ ] Offence and refusal declarations reviewed / 违法与拒签声明已核对

## Purpose and home circumstances / 目的与国内情况

- [ ] Purpose evidence proportionate to claim / 目的证据与申报相称
- [ ] Itinerary consistent with time and budget / 行程与时间、预算一致
- [ ] Employment/study/business/retirement evidence if relied upon / 所依赖的工作、学习、经营或退休材料
- [ ] Personal and economic ties reviewed / 已检查个人及经济联系
- [ ] Return obligations stated truthfully / 如实记录返程责任

## Finance and sponsor / 财务与担保

- [ ] No fixed balance rule invented / 未虚构固定余额要求
- [ ] Trip cost compared with income, savings, and commitments / 已比较旅行费用、收入、储蓄与日常负担
- [ ] Material deposits traced and explained / 重要入账已追溯并解释
- [ ] Funds are accessible and applicant can rely on them / 资金可用且申请人可依赖
- [ ] Sponsor relationship and support scope / 担保关系与支持范围
- [ ] Sponsor ability, willingness, and relevant lawful status / 担保能力、意愿及相关合法身份
- [ ] Form, applicant evidence, and sponsor evidence agree / 表格、申请人与担保材料一致

## Translation and file quality / 翻译与文件质量

- [ ] Every relied-upon non-English/Welsh document has a full translation / 所依赖的非英文或威尔士文材料均有完整翻译
- [ ] Accuracy confirmation / 准确翻译确认
- [ ] Translation date / 翻译日期
- [ ] Translator full name and signature / 译者全名及签名
- [ ] Translator contact details / 译者联系方式
- [ ] Original and translation paired / 原件与译文成对
- [ ] Full pages visible, legible, correctly oriented, and complete / 页面完整、清晰、方向正确
- [ ] Descriptive filenames; live VFS limits rechecked / 描述性文件名且已复核 VFS 当前限制

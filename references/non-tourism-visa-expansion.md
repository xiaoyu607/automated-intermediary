## Promotion rule / 升级规则

For each route: first-party rules and China-specific operations → source register and narrow M1 module → representative fictional case plus adversarial branch and correction log → M2 only at that case/profile granularity → authorised observed applicant case for M3. A routine formal interview route is excluded; if a case-specific interview is ordered, pause it. Keep admission **applications** outside this Skill even when an admission letter is visa evidence.
